# nauka-sistem-patfiz — Контур 1

**Система учета и ведения научной работы на кафедрах и подразделениях.**

- 🌐 Демо-версия: `demo/nauka-system-demo.html` (открыть в браузере)
- 🚀 Развёртывание: `nauka-sistem-patfiz.waw0.amvera.tech`

## Назначение

Единая система научной работы: учет научных работ, направлений, кафедр и подразделений, контроль сроков, динамика результатов, отчетность.

## Основные модули (по демо)

- Дашборд «На повестке» — сводка по научной работе
- Работы по направлениям — тематический план и научные работы
- Последние работы — реестр научных работ
- Динамика результатов — показатели эффективности
- Контроль невыполненных сроков
- Учет по кафедрам и подразделениям
