# Наука · Контур 1 — система учёта научной работы

Внутренняя система отдела науки военного медицинского вуза: публикации, гранты и НИР,
диссертации, изобретения, отчёты подразделений, аналитика и рейтинг исследователей.

**Демо:** https://nauka-sistem-patfiz.waw0.amvera.tech

## Что внутри

| Раздел | Возможности |
|---|---|
| Дашборд | KPI-карточки, активность кафедр, ближайшие сроки, лента событий, рейтинг учёных |
| Научные работы | Реестр с поиском, фильтрами (тип/подразделение/статус), сортировкой, CRUD через модалку с валидацией |
| Канбан задач | Drag-and-drop по статусам или типам работ |
| Подразделения | Карточки кафедр и НИЛ: метрики, выполнение плана публикаций, состав |
| Исследователи | Таблица с авторасчётным рейтингом (активные работы ×2 + публикации ×3 + цитирования ×0.5) |
| Аналитика | Понут-диаграмма структуры, динамика по годам, план/факт по кафедрам |
| Отчёты | Статусы отчётов, шаблоны (4-НИД, грант, рейтинг), экспорт сводного CSV |
| Мероприятия | Интеграция с **Контуром 2** — сайтом мероприятий: nauka-site-patfiz.waw0.amvera.tech |

## Технологии

- **Frontend:** vanilla JS SPA без сборки — модули `js/icons.js`, `js/data.js`, `js/core.js`, `js/pages.js`;
  дизайн-система в `css/style.css` (тёмная/светлая темы, CSS-переменные, адаптив до мобильных).
- **Backend:** FastAPI (`app/main.py`) — отдаёт SPA, статика смонтирована на `/static`.
- Демо-данные живут в `js/data.js`; состояние страницы/темы сохраняется в localStorage.

## JSON API (для интеграции контуров)

- `GET /health` — статус сервиса
- `GET /api/departments` — кафедры и подразделения
- `GET /api/works` — реестр научных работ
- `GET /api/stats` — сводные метрики для виджетов Контура 2
- `GET /api/events` — прокси к мероприятиям Контура 2

## Запуск локально

```bash
pip install -r app/requirements.txt
python -m uvicorn app.main:app --reload --port 8080
```

## Деплой на Amvera

Конфигурация в `amvera.yml`: Python 3.11, точка входа `app/main.py`, порт 8080.
Старое демо сохранено: `/assets/legacy-demo.html`.
