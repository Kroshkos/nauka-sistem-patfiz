# nauka-sistem-patfiz — Контур 1

**Система учета и ведения научной работы на кафедрах и подразделениях.**

- 🚀 Деплой (Amvera): `nauka-sistem-patfiz.waw0.amvera.tech`
- 🔗 Смежный контур: [Контур 2 — сайт с мероприятиями](https://github.com/Kroshkos/nauka-site-patfiz) (`nauka-site-patfiz.waw0.amvera.tech`)

## Структура репозитория

```
amvera.yml                 # конфиг сборки/запуска на Amvera (Python 3.11, FastAPI + uvicorn)
app/
  main.py                  # FastAPI: отдаёт демо + JSON API (/health, /api/departments, /api/works, /api/events)
  requirements.txt
  static/index.html        # демо-версия системы (автономный HTML)
demo/
  nauka-system-demo.html   # исходник демо
```

## Запуск локально

```bash
pip install -r app/requirements.txt
python3 app/main.py        # http://localhost:8080
```

## Основные модули (по демо)

- Дашборд «На повестке» — сводка по научной работе
- Работы по направлениям — тематический план и научные работы
- Последние работы — реестр научных работ
- Динамика результатов — показатели эффективности
- Контроль невыполненных сроков
- Учет по кафедрам и подразделениям

## Интеграция с Контуром 2

Контур 1 получает данные о конференциях и мероприятиях из Контура 2
для формирования отчётов (эндпоинт `/api/events`, позже — прокси на API сайта мероприятий).

## План развития

1. Реальная БД (PostgreSQL/SQLite): кафедры, сотрудники, направления, работы, сроки
2. Роли: сотрудник кафедры, заведующий, научный отдел администрации
3. CRUD научных работ + вложения (PDF), экспорт отчётов (XLSX/PDF)
4. Синхронизация мероприятий из Контура 2
